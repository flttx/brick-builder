# Prototype Plan

### Phase 1：T01~T15

只做纯 Brick Engine：项目骨架、Math、Part、Connector、Spatial Index、Snap、Collision、Graph、Drag Session、Command、Snapshot、Tests。

### Phase 2：T16~T31

接入 R3F/Three.js：Renderer、Instancing、Picking、Camera、Interaction、Drag、Snap Feedback、Detach、Rotate、Undo/Redo、Debug、Benchmark、最终人工验收。
