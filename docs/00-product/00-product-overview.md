# 产品总览

## 产品定位

产品定位为“数字积木玩具”，不是缩小版 CAD。核心体验是：拿一块砖、靠近目标、自然吸附、压下连接、继续搭建。

## 核心使用闭环

进入编辑器 → 随机摇出或指定选择零件 → 放入 3D 场景 → 拖动/旋转 → Snap → 连接 → 继续拼搭 → 自动保存 → 我的作品继续编辑。

## 核心能力

- 零件桶随机抽取
- Part Browser 精确找零件
- Orbit / Zoom / Focus
- Brick Pick / Drag / Rotate
- Stud / AntiStud 连接
- 自动 Snap 与精确 Connector 模式
- Collision Validation
- Detach / Reconnect
- Undo / Redo
- 自动保存、崩溃恢复、我的作品
- 手机和平板适配

## 产品体验原则

场景应占据绝大部分视觉空间，UI 只是浮在场景边缘的轻量 HUD。用户首先感受到“玩”，其次才是“编辑”。
