# 产品范围分级

## Prototype

目标：证明核心数字积木交互成立。

包含：2×4 Brick、少量颜色、Orbit、Zoom、Pick、Drag、90° Rotate、Stud/AntiStud、Snap、Collision、Multi-stud Connection、Detach、Undo/Redo、Debug View。

不包含：账号、数据库、PWA、零件桶、Part Browser、LDraw、Rapier、Audio、Technic、多人。

## MVP

在 Prototype PASS 后增加：

- 16~30 标准 Part，以及基础 Technic Pin / Axle / Bar / Clip 连接件
- Brick / Plate / Tile
- 8~10 种颜色
- Part Browser / Recent Parts / Brick Bucket
- Duplicate / Delete / Change Color
- 基础移动端交互
- IndexedDB Draft / Autosave / Crash Recovery
- Auth / Project CRUD / My Builds / Thumbnail
- PostgreSQL / 基础 PWA

## V1

增加：LDraw 资产管线、30~50+ Parts、LOD、Authoring Tool、完整 Offline、多端冲突、Auto Quality、1000+ Brick 性能优化、Audio/Haptics、Physics Bucket、Telemetry、生产级 CI 与资产发布。复杂 Technic 机构仍不在当前范围内。
